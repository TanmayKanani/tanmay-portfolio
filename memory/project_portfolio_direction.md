User wants Awwwards SOTD-level impact. Rejected atmospheric/editorial direction (too journal-like). Wants:
- Wonder > Atmosphere
- Memorability > Minimalism  
- Large visual moments, 3D depth, mouse-reactive environments
- Competitive Programming as the visual AND emotional centerpiece (not just a text section)
- Simple, human language — visitors experiencing the world, not reading it
- Cinematic transitions, layered parallax, 3D storytelling

**Why:** "I want visitors to feel: I've never seen a portfolio like this before."

**How to apply:** Any implementation must prioritize visual spectacle and world-building over typographic refinement. The world should react to the user. Keep copy minimal — let the visual world carry the experience.
